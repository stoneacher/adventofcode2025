# Advent of Code 2025
This repository contains my solutions to the [Advent of Code 2025](https://adventofcode.com/2025) programming challenges. Each day's challenge is organized into its own directory, containing the problem description, input data, and my solution code.

Problems are often divided into two parts, with the second part unlocking after completing the first. Each part awards one star upon completion. My solutions are implemented in C (or whatever language i feel like writing) and can be compiled and run using the provided Makefiles (if applicable).

Each solution to the first and second part of the problem can be found in the tags in this repository. For example, the solution to Day 1 Part 1 can be found under the tag `D1P1`, and Day 1 Part 2 under `D1P2`.
